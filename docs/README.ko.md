# Token Floor

**별도의 로그인 없이, Claude Code와 Codex 에이전트를 하나의 로컬 픽셀 오피스에서 만나보세요.**

Token Floor는 Claude Code와 Codex가 로컬에 남긴 활동을 실시간 탑다운 오피스로 보여줍니다. 어떤 에이전트가 작업 중인지, 입력이나 권한을 기다리는지, 완료되었는지, 오류가 발생했는지 한눈에 확인할 수 있습니다. 정제된 대화와 이벤트를 읽고, 남은 사용량을 확인하고, 오피스를 직접 돌아다니며 회의실 화이트보드에 프로젝트 메모도 남길 수 있습니다.

Token Floor 계정, 공급자 OAuth 화면, API 키 입력, Claude·Codex 재로그인은 필요하지 않습니다. 컴퓨터에 이미 설정된 공급자의 로컬 상태를 `127.0.0.1`에서 읽으므로 가볍게 시작할 수 있습니다. 공급자 인증정보와 도구 원문 페이로드는 Token Floor에 저장하지 않습니다.

> 현재 Token Floor는 로컬 개발 프리뷰입니다. 설치가 간편한 `npx` 배포 방식은 Phase 05에서 제공할 예정이며 아직 사용할 수 없습니다.

![Token Floor 오피스에서 작업 중인 Claude Code와 Codex 에이전트](assets/agents-working.png)

_메인 에이전트와 서브에이전트는 서로 다른 캐릭터와 작업 위치를 사용하며, 완료된 에이전트는 라운지에서 휴식합니다._

## Token Floor를 쓰는 이유

- **추가 로그인 불필요:** Token Floor 계정, API 키 복사, OAuth 동의, 공급자 재로그인이 없습니다.
- **로컬 우선·읽기 전용:** 공급자 소유 파일은 로컬에서만 읽고, 서버는 루프백 주소에 바인딩하며, 정규화된 런타임 데이터는 Git에서 제외된 `.token-floor/`에 보관합니다.
- **두 공급자를 하나의 언어로:** Claude와 Codex의 서로 다른 기록을 서버와 UI에 전달하기 전에 작은 공통 생명주기 계약으로 바꿉니다.
- **터미널 대신 한눈에 보는 오피스:** 상태, 이동, 말풍선, 사용량, 로그, 메모를 하나의 작은 장면에서 확인합니다.
- **구조적인 안전성:** 추론, 공급자 원문, 도구 입력·결과, 인증정보, 가디언 활동, 내부 오케스트레이션 메시지는 제외합니다.

## 기능

### 실시간 다중 공급자 오피스

- Claude Code와 Codex를 동시에 관찰하며, 한 공급자가 없거나 일시적으로 비정상이어도 다른 공급자는 계속 동작합니다.
- 상단에서 작업 중, 대기 중, 완료, 오류 에이전트 수를 확인합니다.
- 메인 에이전트, 서브에이전트, 공급자별 사용량 NPC를 서로 다른 사전 합성 픽셀 캐릭터로 표시합니다.
- 안정적인 라벨과 역할별 작업 위치를 지정하고, 속도와 멈춤 시간이 다른 직교 경로를 사용해 충돌을 피해 이동합니다.
- 완료된 에이전트는 커피 라운지로 이동하고, 번역된 짧은 휴식 문구를 번갈아 말해 말풍선이 한꺼번에 겹치지 않습니다.
- 작업 공간에서는 말풍선이 사라지지 않으며, 정제된 어시스턴트 메시지, 상태 전환 문구, 휴식 문구 순으로 우선 표시합니다.
- 완료 캐릭터는 60분 동안 유지하되, 재시작 시 이미 보존시간이 지난 캐릭터는 즉시 숨깁니다.

### 상호작용 오피스

- **WASD와 방향키** 모두 같은 4방향 이동·바라보기 규칙으로 캐릭터를 움직입니다.
- 패널, 탭, 메모, 버튼, 화이트보드에 포커스가 있어도 방향키는 항상 캐릭터에 전달됩니다. WASD는 텍스트를 입력할 때만 입력창에 양보합니다.
- 에이전트 작업 공간, 회의실, 커피 라운지, Codex·Claude 전용 사용량 사무실, 미래 공간으로 구성된 아담한 5개 구역을 제공합니다.
- 벽, 회의 테이블, 화이트보드 충돌과 에이전트 우회 경로, 깊이 정렬, 카메라 추적, 휠 확대·축소, 선명한 최근접 이웃 픽셀 렌더링을 지원합니다.
- 캐릭터 선택 패널과 설정에서 여러 플레이어 아바타를 고를 수 있으며 선택값은 로컬에 저장됩니다.
- 오피스에 들어가기 전에 필수 런타임 아트를 확인하고, 누락되면 깨진 장면 대신 확인할 로컬 에셋 경로를 안내합니다.

### 에이전트 상세 정보, 채팅, 이벤트 기록

- 캐릭터를 선택하면 공급자, 상태, 프로젝트, 세션, 최근 활동, 대기·오류 맥락, 부모 에이전트를 상세 패널에서 확인합니다.
- **정제된 채팅**과 **비채팅 생명주기 이벤트**를 별도 탭과 별도 로그로 관리하며 각각 최근 100개까지 유지합니다.
- 정규화된 로그를 SQLite에 저장하고 서버 재시작 후 복구합니다. 로그 보존은 60분 캐릭터 보존과 독립적입니다.
- 중복 기록을 멱등하게 처리하고 이전 이벤트가 더 최신 상태를 되돌리지 못하게 합니다.
- WebSocket이 재연결되는 동안에도 마지막으로 유효했던 오피스 스냅샷을 유지합니다.

### 신뢰할 수 있는 활동·완료 판정

- Codex의 작업, 메시지, 서브에이전트, 함수, MCP, 커스텀 도구, 추론 경계를 공급자 중립 생명주기 이벤트로 변환합니다.
- `mcp_tool_call_begin`, `mcp_tool_call_end`, `agent_reasoning`을 페이로드 없는 활동 하트비트로 처리하여 실제 작업 중인 Codex 에이전트가 5분 뒤 완료로 오판되지 않게 합니다.
- 더 최신 활동 없이 5분이 지났을 때만 완료를 추론하며, 대기 중이거나 실패한 에이전트에는 완료 타임아웃을 적용하지 않습니다.
- 유효하지만 지원하지 않는 기록은 조용히 건너뛰고 실제 원문 손상 상태만 별도로 알립니다.

### 공급자 로그인 없는 사용량 표시

- 공급자 API를 호출하거나 보조 에이전트를 실행하지 않고 공급자가 로컬에 제공한 사용량 제한 메타데이터를 읽습니다.
- 5시간·주간 남은 비율, 초기화 정보, 마지막 동기화 시각, 정보 없음 상태를 각각 표시합니다.
- 상단 사용량 카드나 분리된 사무실의 공급자 NPC를 눌러 같은 상세 정보를 열 수 있습니다.
- Claude CLI·Desktop의 지원되는 로컬 소스 중 가장 최신이며 가장 완전한 유효 표본을 선택합니다.
- Codex의 최근 로컬 rollout 기록에서 사용량을 수집합니다.
- 소스가 없거나 잠겼거나 일부만 기록되었거나 손상되어도 마지막 정상 사용량을 유지하고, 정규화된 값만 원자적 로컬 캐시에 씁니다.

### 화이트보드 메모

- 회의실 화이트보드를 클릭해 메모 패널을 열고 다시 클릭해 닫습니다.
- 최대 1,000자의 메모를 작성하고 `Ctrl`/`Cmd` + `Enter`로 추가할 수 있으며 새로고침, 펼치기·접기, 복사를 지원합니다.
- 일반 메모는 수정하거나 보관할 수 있습니다.
- 보관된 메모는 복원하거나 영구 삭제할 수 있습니다. 일반 메모에는 삭제 기능을 제공하지 않습니다.
- 버전이 있는 메모 JSON을 Git 외부의 `.token-floor/memos.json`에 원자적으로 저장합니다.

### 언어, 설정, 성능 저하 상태

- UI에서 영어, 한국어, 일본어를 지원합니다.
- 언어와 아바타 설정을 브라우저 로컬 스토리지에 저장하고 잘못된 값에는 안전한 기본값을 사용합니다.
- 앱 연결 상태와 공급자별 `정상`, `대기`, `없음`, `오래됨`, `손상`, `연결 끊김` 상태를 독립적으로 표시합니다.
- 인증정보나 공급자 경로를 UI에 요구하지 않고 공급자 기능과 조치 가능한 로컬 소스 진단을 보여줍니다.

### 개인정보 보호 경계

Token Floor는 오피스에 필요한 허용 목록 기반 정규화 필드만 저장합니다. 다음 데이터는 의도적으로 제외합니다.

- Claude·Codex 공급자 원문
- 추론 및 chain-of-thought 내용
- 도구 인자, 입력, 출력, 호출 페이로드, 명령어
- API 키, bearer token, 환경변수 비밀값, 인증정보, 로컬 사용자 이름
- Claude 사이드체인, Codex 가디언 에이전트, 내부 오케스트레이션 프롬프트
- 채팅에 포함된 도구 사용·결과 블록

민감정보 정제는 저장 전에 적용하고, 이전 SQLite 행을 읽을 때도 다시 적용합니다.

## 로컬 실행

### 요구사항

- `node:sqlite`를 포함한 Node.js 22 이상
- npm 10 이상
- 현재 문서화된 Claude Desktop 캐시 경로는 macOS 기준입니다. Claude Code와 Codex 수집기는 사용할 수 있는 공급자 소유 로컬 상태를 읽습니다.

### 시작하기

```bash
git clone https://github.com/haesoo-y/token-floor.git
cd token-floor
npm install
npm run dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)을 여세요. 로컬 수집기·서버는 `127.0.0.1:4317`에서 동작합니다.

Token Floor는 Claude나 Codex 로그인을 별도로 수행하지 않습니다. 컴퓨터에서 공급자를 평소처럼 한 번 설정하면, 공급자가 이미 소유한 로컬 상태를 관찰합니다.

로컬 수집기 대신 결정론적 데모를 실행하려면 다음 명령을 사용하세요.

```bash
TOKEN_FLOOR_SIMULATION=true npm run dev
```

### 주요 명령어

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

## 로컬 데이터

런타임 파일은 Git에서 제외된 `.token-floor/` 아래에 저장합니다.

| 파일                               | 용도                                                            |
| ---------------------------------- | --------------------------------------------------------------- |
| `.token-floor/events.db`           | 재시작 복구용 허용 목록 기반 정규화 생명주기·채팅·사용량 이벤트 |
| `.token-floor/provider-usage.json` | 원자적으로 기록하는 정규화된 사용량 캐시와 마지막 정상 값       |
| `.token-floor/memos.json`          | 버전이 있는 화이트보드 메모 저장소                              |

웹 UI는 Claude나 Codex 파일을 직접 읽지 않습니다. 전체 데이터 흐름과 보안 경계는 [아키텍처 문서](ARCHITECTURE.ko.md)에서 확인하세요.

## 프로젝트 패키지

| 패키지                    | 역할                                                              |
| ------------------------- | ----------------------------------------------------------------- |
| `packages/protocol`       | 공급자 중립 이벤트, 검증, 정제, reducer, 보존, 메모 계약          |
| `packages/adapter-claude` | Claude hook, transcript 복구, 로컬 사용량 해석·정규화             |
| `packages/adapter-codex`  | Codex JSONL 세션·사용량 해석·정규화                               |
| `packages/server`         | 루프백 HTTP·WebSocket 서버, 수집기, SQLite·JSON 영속성, 유지 관리 |
| `packages/web`            | React UI, Phaser 오피스, 패널, 설정, 다국어, 재연결 동작          |
| `packages/asset-contract` | 런타임 에셋 매니페스트와 검증 계약                                |

## 준비 중 — Phase 05

다음 항목은 계획 단계이며 아직 제공하지 않습니다.

- `npx` 실행과 배포 가능한 CLI
